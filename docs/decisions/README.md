# 設計判断の記録 (ADR)

このディレクトリは、コードを読んでも復元できない「なぜそうしたのか」を残す場所です。
1 ファイル 1 決定、**状態 / 文脈 / 決定 / 影響** の 4 節で書きます。

- 番号は連番 (`NNNN-短い説明.md`)。決定を覆すときは**古い ADR を書き換えず**、
  新しい ADR を足して古い方の状態を `廃止` / `置換 (→ NNNN)` に更新する
- 「何をしたか」は git log と PR が持っています。ここに書くのは**却下した案と、
  その理由**です
