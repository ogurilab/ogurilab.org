Sections Kitchen Sink
このページは sections テンプレートの動作確認用です。公開タグを付けていないので、npm run dev のときだけ Draft として表示されます。1行目のタイトルを含めて、この内容をそのまま Cosense のページに貼り付けてください。

[*** ヒーロー：画像＋文章]
[https://gyazo.com/2f592618d6fe19fdaaed3c87372d0fc7]
セクションに画像があってリストが無いときは、図と文章が横に並ぶヒーローになります。段落はふつうに書くだけで、[* 太字]や外部リンク（[https://ogurilab.org ogurilab.org]）もそのまま効きます。

[*** 番号付きカード]
リスト項目に説明を書くと、01 / 02 / 03 の番号付きカードになります。
 [* 文化のデジタル保存] 3Dスキャンや写真測量で、文化財を計測できる形で残します。
 [* 体験としての文化継承] プロジェクションマッピングや各種センサを使い、見て触れて分かるコンテンツを作ります。
 [* コミュニティのためのデータ活用] 文化財を守る人たちの負担を減らすアプリケーションを開発します。

[*** 番号付きカード（説明を次の行に書く）]
タイトルの次の行を1段下げると、その行が説明として下にぶら下がります。
 [* LINE Bot]
  文化財の見守りやスタンプラリーなど、身近な入り口としての Bot を作っています。
 [* VR / XR]
  ヘッドマウントディスプレイを使った空間体験の設計と評価を行います。

[*** カード（Cosense ページから自動取得）]
リンクだけを並べると、リンク先ページの1枚目の画像と説明文を拾ってカードになります。
 [東京ゲームショウ2023に出展しました（2023-09-21）]
 [AITわくわくワールド2023に出展しました（2023-10-15）]
 [2024年度卒研卒制発表会（2025-02-10）]

[*** カード（説明を自分で書く）]
リンクの後ろに文を足すと、リンク先の説明文よりそちらが優先されます。
 [オープンキャンパスに出展しました（2023-07-16）] 高校生に向けて研究内容を紹介しました。
 [半田運河CanalNightイベントに出展しました（2024-08-03）] 地域のイベントに技術で協力しました。

[*** カード（外部リンク・画像なし）]
外部リンクもカードになります。画像が取れないときは頭文字のプレースホルダが入ります。
 [https://ogurilab.org 研究室ホームページ] 現行サイト。
 [https://scrapbox.io/dclab Cosense（dclab）] 一次情報はこちらにあります。

[*** チップ その1：カンマ区切りで書く]
カンマで区切って1行に書くと、タグ無しでそのままチップになります。
 Unity, Blender, TouchDesigner, Next.js, Astro, Python

[*** チップ その2：1行ずつ書く（見た目は その1 と同じになります）]
#chips
書き方が違うだけで、出力は その1 と同じチップです。1行ずつ並べる形はカンマのような手がかりが無いので、#chips で明示する必要があります。効いているかどうかは次のセクションと見比べてください。
 3Dプリンタ
 レーザーカッター
 VRデバイス
 視線計測機器
 高性能デスクトップPC

[*** チップにならない例：タグなしの短い箇条書き]
その2 とまったく同じ形ですが #chips がありません。短いだけの項目はチップにせず、本文の箇条書きのまま残ります。ここが箇条書きで出ていれば、その2 のチップはタグが効いた結果だと分かります。
 Playボタンを押すとスタート
 キーボードの矢印キーで操作できる
 壁があるので下に落ちない

[*** レイアウトを指定して上書きする]
#chips
自動判定だとカードになるところを、見出しの下に置いたタグでチップに変えています。使えるタグは cards / numbered / chips / hero / plain です。
 [Research]
 [Publications]
 [Contact]

[*** 通常の本文]
リストが無いセクションは、これまでどおりの本文としてそのまま出ます。
[** 小見出しも使えます]
`インラインコード`、[* 太字]、Cosense のページリンク（[Research]）が使えます。
> 引用もそのまま出ます。

table:対応するレイアウト
	書き方	結果
	画像だけ	hero
	[Research] のようなリンクの一覧	cards
	説明つきの項目	numbered
	1行にカンマ区切りの語	chips

code:example.ts
 export const template = "sections";

[*** 長い項目は本文のまま]
説明もリンクも無く、かつ長い項目はチップにせず、ふつうの箇条書きとして出します。
 これは1項目がとても長い箇条書きで、チップにしてしまうと読めなくなるためレイアウト判定から外れます。
 もう1行、同じくらいの長さの項目を置いて、本文へフォールバックすることを確認します。
