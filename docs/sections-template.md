# sections テンプレート

セクションを縦に積み上げた「ランディングページ」を、Cosense のふつうの記法だけで書くためのテンプレート。
About / Research / Join / 展示会など、記事ではなく案内として読ませたいページ向け。

- 実装: [`theme/templates/sections.astro`](../theme/templates/sections.astro) と [`theme/lib/sections.ts`](../theme/lib/sections.ts)
- 動作確認用ページの原稿: [`docs/cosense/sections-kitchen-sink.txt`](./cosense/sections-kitchen-sink.txt)

YAML もコードブロックも使わない。**見出しでセクションを切り、並べたいものをリストで書く**、それだけ。
セクションの中身から、どう並べるかが自動的に決まる。

## テンプレートの割り当て

どちらかを行う。

- Cosense のページに `#template/sections` タグを付ける
- `.site` の `code:site.yaml` に書く

```yaml
 templates:
   About: sections
   Research: sections
```

## セクションの切り方

**行の先頭が `[** ...]` 以上の見出しならセクションの区切り**になる。
Cosense は `[* ...]`（アスタリスク1つ）を見出しではなく太字として扱うので注意。

| 記法 | 扱い |
|---|---|
| `[**** タイトル]` | 見出し（最も大きい） |
| `[*** タイトル]` | 見出し |
| `[** タイトル]` | 見出し |
| `[* タイトル]` | 太字（見出しではない） |

1ページの中で**いちばん浅い見出しがセクションの区切り**になり、それより深い見出しはセクションの中の小見出しとして本文に残る。
`[*** ]` と `[** ]` を使ったページなら `[*** ]` が区切り。

ページに見出しが1つも無いときに限り、**単独行の太字（`[* タイトル]`）が見出しの代わり**になる。
Members のように太字で章立てしている既存ページを、書き換えずにそのまま流せる。

見出しの直後の1段落は、セクションの説明文（小さいグレーの一文）になる。
ただし**そのセクションにリストがあるときだけ**。リストの無い、文章だけのセクションは段落をそのまま本文として出す。

## レイアウトの自動判定

セクションの中身を見て、次の順で決まる。

| セクションの中身 | レイアウト | 見た目 |
|---|---|---|
| 画像があり、リストが無い | `hero` | 図と文章が左右に並ぶ |
| 1行にカンマ区切りで語を並べた | `chips` | 丸いタグの羅列 |
| リスト項目が `[ページ名]` や外部リンクで始まる | `cards` | サムネイル付きカードのグリッド |
| リスト項目に説明文がある | `numbered` | 01 / 02 / 03 の番号付きカード |
| 上のどれでもない | `prose` | これまでどおりの本文 |

判定は**意味が1つに定まる合図だけ**で行う。リンクはカード、説明文つきは番号付き、カンマ区切りは語の並び。
短いだけの箇条書きは本文のまま残す（長さで判定すると「Playボタンを押すとスタート」のようなふつうの一文までタグになってしまう）。
1行ずつ並べた語をチップにしたいときは、下の `#chips` を使う。

### hero

```
[*** 研究室について]
[https://gyazo.com/xxxxxxxx]
Digital Culture Lab.（[小栗研究室]）は情報メディア技術を使って…
```

画像が複数あるときは横に並ぶ（縦一列にならない）。

### cards

リンクだけ書けばよい。**リンク先の Cosense ページから1枚目の画像と説明文を自動で取得する**ので、
Gyazo の URL を貼り直す必要はない。Cosense 側でページを更新すればサイトにも反映される。

```
[*** 研究室での活動]
年間を通じて行っている活動です。
 [東京ゲームショウ2023に出展しました（2023-09-21）]
 [AITわくわくワールド2023に出展しました（2023-10-15）]
```

説明文を自分で書きたいときは、リンクの後ろに続ける（リンク先の説明より優先される）。

```
 [オープンキャンパスに出展しました（2023-07-16）] 高校生に向けて研究内容を紹介しました。
```

外部リンクもカードになる。画像が取れないときは頭文字のプレースホルダが入る。
リンク先が `#publish` されていない場合はリンクの無いカードになる。

### numbered

```
[*** 研究領域]
主な研究領域の一覧です。
 [* 文化のデジタル保存] 3Dスキャンや写真測量で、文化財を計測できる形で残します。
 [* 体験としての文化継承] 見て触れて分かるコンテンツを作ります。
```

タイトルの次の行を1段下げると、その行が説明として下にぶら下がる。

```
 [* LINE Bot]
  文化財の見守りやスタンプラリーなど、身近な入り口としての Bot を作っています。
```

### chips

1行にカンマ区切りで並べる。これだけでチップになる。

```
[*** 研究環境・設備]
 3Dプリンタ, レーザーカッター, VRデバイス, 視線計測機器
```

1行に1語ずつ並べたいときは `#chips` を付ける（付けないとふつうの箇条書きになる）。

```
[*** 研究環境・設備]
#chips
 3Dプリンタ
 レーザーカッター
 VRデバイス
```

## レイアウトを指定して上書きする

自動判定を変えたいときだけ、**見出しの下にタグを1行**置く。

```
[*** 研究環境・設備]
#chips
 [Research]
 [Publications]
```

使えるタグは `#hero` `#cards` `#numbered` `#chips` `#plain`（`#plain` は本文のまま）。
タグだけの行はページに表示されない。`#publish` のようなレイアウト名でないタグの行はこれまでどおり表示される。

## 動作確認

`docs/cosense/sections-kitchen-sink.txt` の中身を、1行目のタイトルごと Cosense の新規ページに貼り付ける。
公開タグを付けていないので、`npm run dev` のときだけ Draft として表示され、本番には出ない。

```bash
npm run fetch && npm run dev
```

別のページで試したいときも同じ要領で、`#template/sections` を付けて `#publish` を付けなければ、
開発サーバにだけ Draft として出る。公開中のページを本番に影響させずに試せる。
